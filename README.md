## 📌 Project Overview

**Jenkins Java Project** is a Java-based web application developed as part of a **2.1 Semester Academic Project**.

The repository follows a Maven-based Java web application structure and contains the project's source code under the `src` directory together with a `pom.xml` project configuration file.

The project demonstrates how a Java web application can be organized, built, version-controlled, and integrated into an automated development workflow.
